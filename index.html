연구의 확장
WDSC 2025에서 우수논문상을 받은 벡터 공간 시각화 연구를 확장해, 임베딩 모델의 구조적 특성과 RAG 성능을 비교한 학술지 논문입니다. 아래 실험과 수치는 확장 논문의 공동연구 결과입니다.
연구 목적
OSTEP의 가상화·병행성·영속성 개념이 벡터 공간에서 구분되는지, 이 구조가 검색과 답변 품질에 어떻게 연결되는지 살폈습니다.

교재를 5문장 단위·20% 중첩 청크로 나누고 E5-Small·Base·Large를 PCA와 거리 분석으로 비교했습니다. ANNOY·FAISS(HNSW·IVF-Flat) 인덱스와 Llama-3.1-8B-Instruct를 조합해 10개 질의응답을 RAGAS로 평가했습니다.
주요 결과
실험 범위에서 HNSW + E5-Large가 Faithfulness 0.897, Context Precision 0.852로 가장 높았습니다. 모델 규모가 커질수록 개념 군집이 뚜렷했지만, Large의 평균 인덱스 크기는 17.5MB로 Small(7.2MB)의 약 2.4배였습니다. 소규모 평가에서 품질과 저장 비용의 차이를 확인했습니다.

연구 목적
랜덤 I/O 중심의 최적화 연구에 비해 순차 I/O에서의 할당 정책 분석이 부족하다는 문제에서 출발했습니다. SSD 내부의 Channel·Way·Page를 활용하는 순서에 따라 순차 읽기·쓰기 성능이 어떻게 달라지는지 비교해 워크로드별 선택 근거를 제시했습니다.

주요 결과
실험 범위에서 순차 쓰기는 채널 간 데이터 분산을 활용한 Channel 우선, 순차 읽기는 Way 파이프라이닝을 활용한 Way 우선 정책이 가장 유리했습니다. Page 우선은 병렬성을 충분히 활용하지 못해 I/O Depth가 높아져도 대역폭 증가가 작고 지연이 커졌습니다. 워크로드를 감지해 FTL에서 정책을 동적으로 전환하는 방법을 후속 연구로 제안했습니다.

KCC 2025 / 2025-07-02

RocksDB에서 Compaction Style에 따른 성능 변화 분석

RocksDB의 Leveled·Universal·FIFO Compaction을 비교하고, 처리율만으로는 드러나지 않는 쓰기 비용과 실제 데이터 조회 성공 여부를 함께 분석했습니다.

연구 목적
SST 파일을 병합·정리하는 Compaction 방식이 읽기·쓰기 성능에 미치는 영향을 분석했습니다. 처리율과 지연시간뿐 아니라 쓰기 증폭(WAF), 쓰기 정체(Write Stall), 실제 조회 성공 횟수를 함께 확인해 정책별 장단점을 비교했습니다.
실험 방법
Intel Core i7-1360P·메모리 15GB·Samsung 1TB SSD·Ubuntu 22.04.5 LTS 환경에서 RocksDB의 db_bench를 사용했습니다. 동일 조건으로 값 크기 4KB의 데이터 1,000만 건을 랜덤 쓰기한 뒤 랜덤 읽기를 수행하고, statistics 옵션으로 내부 지표를 수집했습니다.
쓰기 결과
쓰기 작업 시간은 Leveled 1,608.1초, Universal 1,091초, FIFO 533.7초였고, WAF는 각각 4.50·3.43·1.56이었습니다. Universal은 Leveled보다 Compaction 시간이 약 39.8%, Write Stall 시간이 약 48.5% 짧았습니다. FIFO는 파일 병합·정렬을 하지 않아 쓰기 비용이 가장 낮았습니다.
읽기 결과
Leveled의 읽기 처리율은 약 8.41만 ops/s로 Universal의 약 6.47만 ops/s보다 약 1.3배 높았습니다. FIFO는 약 260만 ops/s로 측정됐지만, 실제 조회 성공 횟수는 5,797회로 Leveled 7,134,622회·Universal 7,005,533회보다 약 99.92% 적었습니다. 오래된 데이터를 삭제하는 FIFO의 특성 때문에 높은 처리율을 실제 데이터 조회 성능으로 해석하기 어려웠습니다.
의미·한계
읽기 중심 작업에서는 Leveled, 쓰기 비용과 읽기 성능의 균형에서는 Universal의 이점을 확인했습니다. FIFO는 데이터 보존 요구까지 고려해야 하며, 처리율·지연시간과 조회 성공 여부를 함께 평가해야 합니다. 계층별 정책을 조합하는 Tiered Compaction과 읽기·쓰기 혼합 워크로드 실험은 후속 연구로 제안했습니다.
