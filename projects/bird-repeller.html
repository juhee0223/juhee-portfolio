기여와 역할

아이디어 제안, 퇴치음 조사·음원 제작, API 요청에 따른 소리 재생 기능 구현, 발표자료 제작과 발표를 맡았습니다. 조류 탐지는 팀 공동 산출물입니다.

결과

팀이 조류 탐지와 소리 재생을 연결한 프로토타입을 완성해 KHUTHON 2025 우수상을 받았습니다.

조류 탐지와 기피음 재생 연계

농업의 기술화를 주제로 한 해커톤에서 농작물을 먹는 유해조류 문제에 착안했습니다. 새를 감지하면 퇴치음을 재생하고 웹에서 감지 이미지와 출력 기록을 확인하는 방안을 제안했습니다.

음원 재생 기능 구현 및 발표

퇴치음을 조사하고 음원을 제작했으며 API 요청에 따라 소리를 재생하는 기능을 구현했습니다. 팀의 조류 탐지 결과와 재생 기능을 연결하고 발표자료 제작과 발표를 맡았습니다.

팀은 프로토타입을 완성해 KHUTHON 2025 우수상을 받았습니다. 실제 농가에서의 조류 피해 감소를 검증한 결과는 아닙니다.
