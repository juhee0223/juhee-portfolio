  • 봉사 인력 부족과 새로운 만남의 수요를 연결하는 서비스 제안

온보딩 입력 검증과 매칭 화면 연결

가입·프로필

  • 8자리 학번 형식 검증 · 재학증명서 파일 선택 및 필수 입력 검증
  • MBTI 선택 · 지역 목록 · 선호 봉사 카테고리 입력 흐름 보완

매칭 UI

  • 선호 봉사 카테고리 필터 · 후보 카드 선택 · 매칭 요청 UI 구현

화면 연결

  • Q&A 스레드·질문함 화면 보완 · 로그인·온보딩·매칭 라우팅 연결 참여

구현 경계

  • 클라이언트 입력·화면 작업 · 일부 mock API 기반 흐름 포함
  • OCR·서버 학생 검증·봉사활동 신청 API는 개인 구현으로 표기하지 않음
