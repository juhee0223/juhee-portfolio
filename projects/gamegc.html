GC 정책과 실행 방식
구분선택·실행 기준비교 관점
Greedyinvalid slice 수가 많은 block부터 victim 선택정책별 GC 동작 비교
Cost-Benefitinvalid/valid page · block age 기반 scorevictim 선택 기준의 차이 확인
GameGCfree block 임계값 · scheduling tick · page limit페이지 이동을 나누어 처리하는 pipeline 방식

공개 코드의 구현 구조를 정리한 표이며, 정책별 성능 우열이나 지연 개선 수치를 의미하지 않습니다.
