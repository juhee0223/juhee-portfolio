04 / Problem solving

문제 해결과 검증

부분 점수의 한계를 고려한 제출 방향 제안

문제

  • 점검 당시 최고 대시보드 점수안: 외부 검색 없이 응답 지침 적용
  • 외부 검색 추가 발전 의견과 일부 문항 점수에 맞출 경우 정식 평가 성능 저하 우려 제기

접근

  • 부분 점수만으로 정식 평가 성능을 단정할 수 없다는 한계 인정
  • 남은 시간 내 제출안 완성을 위해 현재 비교에서 가장 좋은 구현을 출발점으로 삼자고 제안
  • 점수와 의료 상담의 답변 요건을 함께 검토할 필요성 판단
01

비교한 구현

외부 검색 활용안 / 응답 지침 중심안

함께 본 제약

03

공동 보완

현재 최고 점수안을 기준으로 의료 답변 요건 검토

HealthBench 기준을 의료 응답 규칙으로 구체화

개선 기준

  • 팀 방향 결정 후 HealthBench 의료 대화 평가 기준 분석 · 응답 규칙 공동 개선
  • 질문의 모든 요구에 답변 · 위험 신호 안내 · 판단에 필요한 사용자 정보 확인 규칙 구체화

접근·공동 구현

  • 정보가 부족해도 현재 제공 가능한 설명을 먼저 제시하도록 지침 보완
  • 기존 생성 요청에 규칙 반영 · 별도 모델 호출 증가 없음
  • 응답 규칙 개선 및 제출 구현은 팀 공동 작업
