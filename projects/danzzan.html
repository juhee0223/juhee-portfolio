네이버페이 페이스사인 협업 · 봄축제 입장 연계

단짠 예매 유지 → 날짜별 예매자 명단 전달 → 페이스사인 현장 입장

개인 참여: 협업 범위·명단 전달 기준 조율 및 가입 흐름 반영 · 얼굴 인증은 협력사 담당

협업 과제

  • 축제 한 달 전 네이버페이 얼굴인증 입장 서비스 협업 제안
  • 기존 예매 기능 유지 및 정해진 일정 내 입장 연계 준비

범위 결정

  • 신규 로그인 API 연동 대신 단짠 예매 유지 방안 제안
  • 가입 시 수집한 네이버 아이디를 예매자 명단으로 전달
  • 협력사 역할·일정 제약 확인 후 팀과 협업 범위 결정

연계 기준

  • 동일 네이버 아이디의 양일 예매에도 날짜별 입장 권한 구분 필요
  • 명단 처리 기준·수정분 전달 범위 확인 및 전체 명단 대조 방식 합의
  • 가입 흐름에 안내·입력란·개인정보 동의 반영

검증·운영

  • 학과 학생에게 실제 가입 테스트 요청 · 예매자 명단 추출 시험
  • 봄축제 페이스사인 입장 실제 운영
  • 관리자 화면에서 예매 정보 조회 및 현장 팔찌 배부
04 / Problem solving

문제 해결과 검증

번역 누락 복구: 로그·DB·영어 화면으로 확인

운영 중 발견한 번역 누락 복구 / 실제 번역 대상과 신규 공지로 확인

문제

  • 봄축제 유학생 이용 불편을 바탕으로 팀이 가을축제에 영어 지원 도입
  • 운영 중 번역 누락 발견 · 번역 기능 구현 담당자와 협의 후 복구 담당

접근

  • Docker Compose 서버 로그 확보 · AI 도구와 원인 분석
  • 원인: 번역 영문의 MySQL 컬럼 길이 초과 → 전체 저장 롤백 및 동일 데이터 반복 번역
  • AI 활용 컬럼 확장 · 저장 트랜잭션 행별 분리

결과

  • 처리 로그 0 확인 후에도 AI 제안에 따라 DB 잔여 데이터 점검
  • 조회 조건을 실제 번역 대상과 일치시키고 공백 데이터 정리 → SQL로 미번역 대상 0건 확인
  • 새 공지 자동 번역·저장·영어 화면 표시까지 검증
복구 검증미번역 대상 0건
